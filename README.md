# 企业问题会诊专家团 (Enterprise Consult Expert Team)

WorkBuddy Team 型专家包：像名医会诊一样诊断企业难题——战略、财务、组织、运营、市场、风控、数字化七路专科顾问联合会诊，定位根因并开出可落地的整改处方。

| 成员 | 名字 | 职责 |
|------|------|------|

| 组织人力专家 | 任聚才 | 组织架构、人才梯队、激励考核、企业文化 |
| 运营流程专家 | 刘畅 | 流程效率、瓶颈定位、交付质量、内部协同 |
| 市场增长专家 | 金拓新 | 获客转化、渠道 ROI、客户分层、复购留存 |
| 风控合规专家 | 杜渐微 | 风险地图、合规扫描、合同风险、处方副作用预审 |
| 数字化转型顾问 | 陆云桥 | 数字化成熟度、系统版图、数据资产、自动化改造 |

## 会诊流程（SOP）

```
Phase 0 问诊澄清 → Phase 1 分科体检(并行) → Phase 2 病例整合
→ Phase 3 联合会诊定位根因(用户确认) → Phase 4 开处方(30/60/90天路线图) → Phase 5 复诊
```

预设工作流：WF1 全科经营会诊 / WF2 专科直调 / WF3 现金流急救。

主理人调度成员时会按「知识库调度规则」要求各成员读取对应文件，产出须标注引用来源。

## 核心方法论

- **三不原则**：无证据不诊断、不头痛医头、不开空处方
- **P0 绝对规则**：禁止正确的废话 / 禁止无依据断言 / 禁止越界违规建议
- **处方四要素**：动作 + 责任人 + 时限 + 验证指标
- **ConsultVerdict**：结构化回传协议，发现/根因假设/处方/数据待补清单一目了然

## 安装

将 `enterprise-consult-expert-team/` 目录放入 WorkBuddy 专家目录：

```
~/.workbuddy/plugins/marketplaces/my-experts/plugins/enterprise-consult-expert-team/
```

然后运行注册命令使其在专家中心可见（注册脚本见 WorkBuddy 内置 expert-manager 技能）：

```bash
python3 scripts/register_expert.py <expert-dir>
```
