# 企业问题会诊专家团 (Enterprise Consult Expert Team)

WorkBuddy Team 型专家包：像名医会诊一样诊断企业难题——1 位首席会诊官 + 7 位专科顾问（战略/财务/组织/运营/市场/风控/数字化）联合会诊，定位根因并开出可落地的 30/60/90 天整改处方。

## 仓库内容

| 路径 | 内容 |
|------|------|
| `enterprise-consult-expert-team/` | 专家包完整源码（v1.1.2）：plugin.json、7+1 个 Agent 定义、9 张头像、8 篇方法论知识库 |
| `会诊报告-智造科技-2026-09-16.md` | 模拟案例完整产出：非标产线集成商 7 症状并发会诊报告（含能力复盘自评） |

## 专家团速览

- **SOP**：问诊澄清 → 分科体检(并行) → 病例整合 → 联合会诊定位根因(用户确认) → 开处方 → 复诊
- **P0 铁律**：禁止正确的废话 / 禁止无依据断言 / 禁止越界违规建议
- **处方四要素**：动作 + 责任人 + 时限 + 验证指标
- **预设工作流**：WF1 全科会诊 / WF2 专科直调 / WF3 现金流急救
- **知识库**：诊断框架、行业基准、转型打法库、病历模板（references/）

## 安装

将 `enterprise-consult-expert-team/` 放入 WorkBuddy 专家目录并注册：

```
~/.workbuddy/plugins/marketplaces/my-experts/plugins/enterprise-consult-expert-team/
```
