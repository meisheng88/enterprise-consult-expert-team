# 经营扭转打法库：止血 / 治本 / 调理三级干预

> 主要适用：主理人甄明断（处方整合排序）、全员（处方设计）。Phase 4 开处方时使用。

## 一、三级干预框架

| 级别 | 目标 | 时限 | 特征 |
|------|------|------|------|
| 止血项 | 阻止恶化，保住命 | 0-30 天 | 见效快、可逆、不需要大投入 |
| 治本项目 | 解决主根因 | 30-90 天 | 动结构、动机制，需要管理层投入 |
| 调理项 | 建长效机制防复发 | 90 天以上 | 制度化、系统化、文化建设 |

**排序铁律**：止血先行但不止于止血——只止血不治本 = 拖延死亡；只治本不止血 = 还没治好人就没了。

## 二、止血打法库（按症状）

| 症状 | 常用止血动作 | 验证指标 |
|------|-------------|---------|
| 现金流告急 | 应收专项清收（名单+责任人+期限）；非必要支出冻结；应付协商展期 | 现金安全月数回升至 3 个月以上 |
| 大客户流失 | 创始人/高管直管挽留 top 客户；成立交付保障专班 | 流失客户数归零 |
| 交付失控 | 订单分级（保关键客户）；每日交付晨会；瓶颈环节临时增援 | 准时交付率周环比改善 |
| 核心人才流失 | 关键人一对一保留面谈；临时留任激励 | 关键岗位离职冻结 |
| 库存积压 | 停止非畅销品补货；折价清仓通道 | 库存周转天数月环比下降 |

## 三、治本打法库（按根因类型）

| 根因类型 | 典型治本动作 | 联动科室 |
|----------|-------------|---------|
| 战略迷失 | 聚焦主业、砍掉失血产品线、重选目标客群 | 战略+财务 |
| 模式失效 | 定价体系重构、UE 转正路径设计 | 战略+市场+财务 |
| 组织失效 | 组织架构调整、权责重划、考核激励重建 | 组织+运营 |
| 流程断点 | 端到端流程再造、瓶颈环节专项改造 | 运营+数字化 |
| 数据盲区 | 经营报表体系、数据口径统一 | 数字化+财务 |
| 风险失控 | 内控体系重建、合同模板与审批权限整改 | 风控 |

## 四、调理机制库（防复发）

- **经营例会机制**：月度经营分析会（固定议程：指标回顾 → 偏差归因 → 行动项跟踪）
- **预警指标体系**：为每个主根因设置先行指标（如客户流失的先行指标 = 交付延期率、投诉率）
- **复盘机制**：重大事项事后复盘（AAR：原计划/实际结果/偏差原因/经验固化）
- **关键人备份**：关键岗位 AB 角，知识文档化，降低个人依赖

## 五、处方失败红线（自检）

| 红线 | 检查问题 |
|------|---------|
| 处方超过企业消化能力 | 同时开 >5 个治本项目 = 哪个都推不动。90 天内治本项目 ≤3 个 |
| 无人背锅 | 每条处方有唯一责任人（岗位而非"相关部门"） |
| 无验证闭环 | 每条处方有验证指标 + 检查时间点 |
| 只给方案不给排序 | 处方必须分止血/治本/调理三级，标注先后 |
| 忽略副作用 | 每条处方过风控预审（如裁员处方的法律与士气风险） |
