# 企业问题会诊专家团 - 咨询方法论知识库

本知识库为专家团各成员提供专业弹药。主理人在 spawn 成员时，必须在指令中指明该成员需要读取的知识库文件（调度映射见主理人 MD 的「知识库调度规则」）。

## 目录结构

```
references/
├── 01-frameworks/          诊断框架层——怎么分析问题
│   ├── diagnostic-toolkit.md    假设驱动、议题树、MECE、5Why、鱼骨图、根因下钻标准
│   └── classic-models.md        经典模型速查：五力/SWOT/商业画布/7S/BSC/价值链/安索夫
├── 02-benchmarks/          基准数据层——判断"正常还是异常"
│   ├── financial-vitals.md      财务体检指标表与分行业参考区间
│   └── growth-ops-metrics.md    增长与运营指标基准（CAC/LTV/留存/转化率/交付周期）
├── 03-playbooks/           打法库——怎么解决问题
│   ├── digital-transformation.md  数字化成熟度四级模型、路线图模板、失败模式
│   └── turnaround-playbook.md     经营扭转打法：止血/治本/调理三级干预
└── 04-templates/           模板层——标准化产出
    ├── intake-checklist.md        分科问诊数据采集清单
    └── case-file-templates.md     初诊病历 / 综合病历模板
```

## 使用原则

1. **框架是脚手架不是枷锁**：模型用于结构化思考，禁止为套模型而套模型
2. **基准是参照不是判决**：行业基准仅为参考区间，偏离基准 ≠ 有问题，要结合企业阶段判断
3. **引用必标注**：成员产出中引用知识库内容时，标注来源文件（如"参照 financial-vitals.md 应收周转基准"）
4. **知识库不替代调研**：联网调研获取的最新数据优先于知识库中的静态基准
